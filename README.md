# Numerical methods in MATLAB

This is a cleaned collection of MATLAB work from my numerical-computation course. I grouped several assignments in one repository because they are short studies of related numerical ideas rather than separate software projects.

The code covers topics such as:

- Jacobi and Gauss-Seidel iteration for linear systems.
- Newton's method for nonlinear systems.
- Numerical differentiation and error comparison.
- Euler's method compared with MATLAB's `ode45`.

Each `hw*/` directory contains the code and selected output files that belonged to that assignment. Submission PDFs, reference textbooks, exam archives, and instructor solutions were left out.

## Running

Open an individual `.m` file in MATLAB and run it from its own folder. A few files define local helper functions and should be run as scripts or functions according to their first line.

## Scope

This repository documents coursework and learning progress. It is not intended to replace a tested numerical-methods package, and the examples use the tolerances and test cases specified in the assignments.
